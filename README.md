# Basic Mobile Robot - ROS 2 Workspace

## 1. Project Overview

This repository contains a ROS 2 workspace used to build and simulate a basic differential-drive mobile robot from scratch.

The project was created as a practical ROS 2 learning project using:

- ROS 2 Jazzy
- Gazebo Sim
- URDF
- `robot_state_publisher`
- `ros_gz_bridge`
- Gazebo DiffDrive
- Python
- Custom keyboard teleoperation
- Git and GitHub

The robot consists of:

- One main base
- Two driven wheels
- One supporting caster

## 3. What This Project Does

This project creates a basic mobile robot and runs it inside Gazebo. The robot can be controlled using a custom keyboard teleoperation program.

The complete movement process is:

```text
Keyboard
   ↓
custom_teleop.py
   ↓
ROS 2 /cmd_vel
   ↓
ros_gz_bridge
   ↓
Gazebo /cmd_vel
   ↓
Gazebo DiffDrive
   ↓
Left and Right Drive Wheels
   ↓
Robot Movement
```

---

## 4. Robot Description

The robot is defined using the URDF file:

```text
src/basic_mobile_robot/urdf/basic_mobile_robot.urdf
```

### Links
- `base_link`
- `left_wheel_link`
- `right_wheel_link`
- `caster_link`

### Joints
- `left_wheel_joint` (continuous)
- `right_wheel_joint` (continuous)
- `caster_joint` (fixed/continuous connection to base)

The two drive wheels are continuously rotating joints, while the supporting caster stabilizes the base.

---

## 5. Differential Drive Configuration

Gazebo uses its DiffDrive plugin to control the robot's two drive wheels.

- **Left joint:** `left_wheel_joint`
- **Right joint:** `right_wheel_joint`
- **Wheel separation:** `0.45 m`
- **Wheel radius:** `0.10 m`
- **Command topic:** `/cmd_vel`

---

## 6. ROS 2 and Gazebo Bridge

The project uses `ros_gz_bridge` to connect ROS 2 communication with Gazebo communication.

The velocity command is transferred between:

```text
ROS 2: geometry_msgs/msg/Twist
               ↓
         ros_gz_bridge
               ↓
Gazebo: gz.msgs.Twist
```

- **Bridged Topic:** `/cmd_vel`
- **Purpose:** Enables the ROS 2 keyboard controller to communicate directly with the Gazebo DiffDrive system.

---

## 7. `robot_state_publisher`

The launch file starts `robot_state_publisher`, which reads the URDF description and broadcasts the robot's TF transforms and state information required across the ROS 2 system.

cd ~/basic_robot_ws
ls

## 11. Source ROS 2

Before building, source the ROS 2 Jazzy environment in your terminal:

```bash
source /opt/ros/jazzy/setup.bash
```

---

## 12. Build the Workspace

Navigate to the workspace root and build using `colcon`:

```bash
cd ~/basic_robot_ws
colcon build --symlink-install
```

---

## 13. Source the Workspace

Source the local overlay to make your package available:

```bash
source ~/basic_robot_ws/install/setup.bash
```

---

## 14. Check That the Package Is Available

Confirm that ROS 2 detects the package:

```bash
ros2 pkg list | grep basic_mobile_robot
```

Expected output:
```text
basic_mobile_robot
```

---

## 15. Launch the Robot Simulation

Open a terminal and run:

```bash
source /opt/ros/jazzy/setup.bash
source ~/basic_robot_ws/install/setup.bash
ros2 launch basic_mobile_robot basic_mobile_robot.launch.py
```

This starts:
- Gazebo Sim
- `robot_state_publisher`
- ROS 2 ↔ Gazebo `/cmd_vel` bridge
- Spawning of the differential robot model

*Keep this terminal running.*

---

## 16. Run the Custom Keyboard Teleoperation

Open a **second terminal** and run:

```bash
source /opt/ros/jazzy/setup.bash
source ~/basic_robot_ws/install/setup.bash
ros2 run basic_mobile_robot custom_teleop.py
```
